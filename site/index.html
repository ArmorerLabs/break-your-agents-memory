How it works

  1. This page (later: our own website) holds the lesson, the story, and the launch button.
  2. Colab is the backend: the button opens each participant's own copy of the notebook on Google's machines — no install, no shared-VM collisions, saved to their Drive.
  3. The lab runs offline at $0 (fixtures/replay), so nobody needs an API key. Live mode is optional, bring-your-own-key.
  4. Scores are computed in the notebook from the run folders — the same scorer, the same pass rule, evidence labels included.

If the platform fails

GitHub Codespaces (the repo ships a devcontainer), or a local pip install from a zip.

Everything down

Facilitator runs the baseline on the projector in replay mode; the room traces the committed screenshots.
